# Internal hiring

Audience: INTERNAL_RESTRICTED

This directory is hiring material. It is not product documentation, not a customer artifact, and not an external announcement.

`docs/internal/` is already on the documentation packaging deny list (`docs/governance/PACKAGING-EXCLUSION.json`). These files stay on that path so a public package build does not pick them up. The repository itself is public; the audience label is a handling rule for people and agents, not an access control.

## Packages

| Package | Path | Offer status |
| --- | --- | --- |
| Head of Product / Head of Product Engineering | `head-of-product/` | The only hiring package in this change |
| CTO evaluation framework stub | `cto-evaluation/FRAMEWORK-STUB.md` | Separate future document. Not an offer exhibit |

WS13 force: Head of Product or Head of Product Engineering. Founder, co-founder, technical co-founder, guaranteed CTO, and automatic CTO succession are outside this package.
