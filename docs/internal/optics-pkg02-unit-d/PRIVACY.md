# PKG-02 Unit D privacy

PRIVATE | FUTURE LINE | NOT PUBLISHED | NOT SEALED | NO UNIT E | NO STABLE SCHEMA

Audience: INTERNAL_RESTRICTED

The writer does not copy request or response bodies. An ordinary-client `POST` body `SECRET_PROMPT_CANARY` is absent from the file.

The writer does not call `os.hostname()` and does not store a machine hostname. `destination_host` is the remote host the interceptor already recorded.

The writer does not copy `est_spend_usd`, `free_mode`, `plane`, `data_note`, or `residual`. `error` strings are not stored. A thrown error contributes `error_class` only when the name is a token of letters, digits, and underscore. `err.message` is not read into the record.

`application_result` is returned to the caller of `composeCanonical`. It is not written into the file.

The inert adapter is still the reader of copies. Proving it is present does not rewrite the `0.3.24` file.
