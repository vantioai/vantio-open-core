# PKG-02 Unit E rollback

Audience: INTERNAL_RESTRICTED

Disable the new writer with `set_writer_mode("legacy")` or `VANTIO_PKG02_PYTHON_WRITER=legacy`.

The next `shield()` that saw a call writes the previous shape. The stored call path omits the query. The file includes `summary` with the same fields sealed `3.1.0` writes for that call. The next empty `shield()` writes no file. A canonical file already written stays on disk with `evidence_origin` `LOCAL_OBSERVATION`.

`read_rolled_back(path)` is the reader that no longer understands the canonical bundle. It returns `optics_status` `UNSUPPORTED` and the file's `schema_status`. It does not rewrite the file and it does not map the status to `SUCCESS`.

Customer exception text stays off the record. The stored token is `error_class` when the contract accepts that token. A validator failure does not change the wrapped function's return value.
