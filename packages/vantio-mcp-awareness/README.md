# @vantio/mcp-awareness

In-process parser and operator policy for MCP JSON-RPC on stdio, HTTP, and SSE.

This package is the gap-track T4 library. It is not Phantom Engine, and it does not extend Phantom Engine beyond enrolled Linux. Host attachment is Roadmap.

Node `vantio run` loads it in-process. The default is observe, with injection and rug-pull set to log. `--mcp-enforce` opts in to withhold. `VANTIO_MCP_AWARENESS=off` leaves it unloaded. The register does not open a socket. Records do not store payload text.

Public pricing language is Contact Vantio. This package is not a release.
