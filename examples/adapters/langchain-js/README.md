# LangChain.js + Vantio Optics

Zero code changes for observe — wrap the process:

```bash
npm install -g @vantio/cli
vantio run node agent.js
```

Optional `shield()` for a single trace id — see [framework-integrations.md](../../../docs/framework-integrations.md).

For policy dry-run in the IDE, add `@vantio/gate-mcp`.
