# Vantio Optics — VS Code extension

Thin commands over the CLI:

- **Vantio: Export Optics proof**
- **Vantio: Discover local LLM hosts**
- **Vantio: Show upgrade path**

Requires `npm install -g @vantio/cli`.

Publish later to the VS Code Marketplace as `vantioai.vantio-optics`. For Cursor, prefer the [Cursor plugin](https://github.com/vantioai/vantio-optics-cursor-plugin).
